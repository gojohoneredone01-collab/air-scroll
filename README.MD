# 🚀 AirScroll: Contactless Gesture Presentation Controller

An AI-powered computer vision project built to solve stage and presentation friction by enabling touch-free scrolling and clicking via webcam hand gestures.

## 🛠️ Tech Stack
- **Python** (OpenCV, MediaPipe, PyAutoGUI)
- **Frontend** (HTML5, Tailwind CSS)
